# Добро пожаловать в CorporationX Wiki! 🚀

В этом репозитории используются несколько сервисов в виде Git submodules. Они обеспечивают гибкость и масштабируемость проекта.

## Список сервисов:
- [Post Service](https://github.com/ArseniAstonMartin/post_service) – управление постами, News Feed.
- [Project Service](https://github.com/ArseniAstonMartin/project_service) – администрирование проектов.
- [User Service](https://github.com/ArseniAstonMartin/user_service) – управление пользователями.
- [Notification Service](https://github.com/ArseniAstonMartin/notification_service) – обработка событий и отправка уведомлений на Telegram, Mail, SMS.
- [URL Shortener Service](https://github.com/ArseniAstonMartin/url_shortener_service) – сокращение ссылок.
- [Account Service](https://github.com/ArseniAstonMartin/account_service) – управление платёжными аккаунтами.
